# 完整测试记账 APP

针对「记账 APP」这个项目，运行全部测试并汇报结果，按下面步骤：

1. 运行 `npm test`（会跑完全部测试：工具函数、数据库计算逻辑、页面组件，共 35 个用例）。
2. 根据运行结果，生成一份测试报告告诉用户：总共几个测试、通过几个、失败几个。
3. 如果全部通过，告诉用户「所有测试通过，APP 各环节正常」。
4. 如果有测试失败，判断是「代码有 bug」还是「测试写错了」，用大白话说明原因，并给出修复建议；修好后重跑直到通过。

## 这套测试覆盖了什么（大白话）

- **工具函数**（`src/utils.ts`）：金额换算、日期加减这些纯计算。
- **数据库计算逻辑**（`src/db-logic.ts`）：收支汇总、筛选条件拼接、月份补齐这些规则。
- **页面组件**（`src/views/*.vue`）：记账校验、账单金额显示、删除确认、分类新增、菜单切换等行为。

## 写测试时要注意的坑（遇到报错先看这里）

- **页面组件要用「假浏览器」**：每个组件测试文件顶部必须有 `// @vitest-environment jsdom` 这行，否则会报 `document is not defined`。
- **数据库要用「假数据」**：组件测试里用 `vi.mock('../db', ...)` 替换真实的数据库模块，避免测试时真的去读写 SQLite。
- **图表（ECharts）和贪吃蛇画面测不了**：用假对象替代，只测行为逻辑（比如「拉没拉数据」「点开始按钮状态对不对」），不测画面画得对不对。
- **报错 `Cannot read properties of undefined (reading 'config')`**：是 Vite 的异步配置跟 Vitest 不合拍，确认项目里有独立的 `vitest.config.ts`（同步、简单配置）。
- **jsdom 缺浏览器 API**：`test-setup.ts` 里已经补齐了 ResizeObserver、matchMedia，别删它。
